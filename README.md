# PLGRM

Демонстрационный B2B сайт производства технической верхней одежды.

Адрес: https://vadimsas.github.io/plgrm/

GitHub Pages публикует ветку main из корня. Статический сайт без этапа сборки; .nojekyll сохраняет готовую структуру.

12 направлений, производство, карточки изделий, галереи и мобильная версия. Форма готовит локальный TXT бриф и не отправляет персональные данные. Реальные заявки, CMS и рабочие контакты пока не подключены.

Компоненты: Bootstrap 5.3.3; шрифт Manrope. Фото изделий: PLGRM; пейзажные иллюстрации: Unsplash. Источники указаны на странице credits.
